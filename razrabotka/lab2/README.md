# Задание 2 — вариант C2

## Файлы
- `explicit_euler.py` — явный метод Эйлера.
- `implicit_euler.py` — неявный метод Эйлера.
- `common.py` — тестовые функции, модель ИИМ, метод прогонки.

## Установка
```bash
python -m pip install numpy matplotlib
```

## Запуск теста
```bash
python explicit_euler.py --N 40
python implicit_euler.py --N 40 --dt 0.01
```

## Заготовка под параметры преподавателя
В каждом файле предусмотрен ключ `--teacher`:
```bash
python explicit_euler.py --N 40 --teacher
python implicit_euler.py --N 40 --dt 0.01 --teacher
```
Перед этим заполните функции и параметры в `teacher_parameters()` файла `common.py`.

## Замечания
- Тест: точное решение `u(r,t)=exp(-t)*(1+r**2)`, `R=T=1`, `k=1`, `q=0`,
  `f=-(5+r**2)*exp(-t)`, `phi=1+r**2`, `v=2*exp(-t)`.
- Для явной схемы программа печатает оценку ограничения шага времени
  `dt <= h^2/(4*k_max)`. Это ориентировочная консервативная оценка для диффузионной части,
  а не универсальное доказательство устойчивости для произвольных переменных коэффициентов.
- Формулы в узлах оси и внешней поверхности получены интегрированием уравнения с цилиндрическим весом `r`.

## Выбор теста с точным решением

Оба решателя поддерживают два теста:

- тест 1: `u(r,t) = exp(-t) * (1 + r^2)`;
- тест 2: `u(r,t) = exp(-t) * (1 + r^4)`.

Примеры запуска:

```bash
python explicit_euler.py --N 40 --test 1
python explicit_euler.py --N 40 --test 2
python implicit_euler.py --N 40 --dt 0.0005 --test 1
python implicit_euler.py --N 40 --dt 0.0005 --test 2
```

## Автоматические проверки

```bash
python test_suite.py
```

Скрипт проверяет метод прогонки на системе с заранее известным решением, согласованность начальных и граничных данных обоих тестов, а также запуск явного и неявного методов на обоих тестах.
