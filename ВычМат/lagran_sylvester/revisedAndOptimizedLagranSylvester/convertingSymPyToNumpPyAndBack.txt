Чтобы преобразовать матрицу из SymPy в NumPy, ты можешь использовать метод .tolist() и передать результат в np.array(). Вот простой способ:

✅ Преобразование SymPy → NumPy:
python
Копировать
Редактировать
import sympy as sp
import numpy as np

# Пример sympy-матрицы
M = sp.Matrix([[sp.sqrt(2)/2], [1/3]])

# Преобразуем в NumPy-массив с float-значениями
M_np = np.array(M.tolist(), dtype=np.float64)

print(M_np)
⏳ Если значения не численные (символьные):
Если матрица содержит нечисленные символы (например, x, sqrt(2), pi), то сначала её нужно численно вычислить (сделать evalf()):

python
Копировать
Редактировать
# Пример
M = sp.Matrix([[sp.sqrt(2)/2], [1/3]])

# Преобразование с вычислением чисел
M_np = np.array(M.evalf().tolist(), dtype=np.float64)
